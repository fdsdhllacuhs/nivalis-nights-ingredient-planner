## Overview

Nivalis Nights Ingredient Planner is a companion tool for Nivalis Nights that maps every craftable recipe's ingredient requirements, the in-game vendors and locations that sell each ingredient, and the optimal shopping route for acquiring all materials for a planned menu. It covers the game's full cooking and bartending crafting system.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Nivalis Nights Ingredient Planner** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Recipe Index** | Complete list of all craftable recipes with full ingredient breakdowns |
| **Vendor Map** | Shows which vendors and locations sell each required ingredient |
| **Shopping Route** | Optimized vendor visit order for acquiring all required ingredients |
| **Menu Planner** | Plan multiple recipes simultaneously and aggregate their ingredient needs |
